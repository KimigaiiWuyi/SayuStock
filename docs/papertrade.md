# SayuStock AI 模拟盘

一个部署里可以同时开多个**命名模拟盘**。每个盘有自己的现金、持仓、账本和策略，互不干扰。

盘**不属于某个群**。任何群都能查任何盘；群和盘之间唯一的关系是：这个群订不订阅那个盘的成交播报。

早柚在 A 股交易日每隔 30 分钟给每个**启用中**的盘看一次盘。真成交时，向订阅了该盘的群发一行冒泡。

你能做的：建盘、改名、换策略、启停、订阅播报、只读查询。  
你不能做的：指挥买哪只、改单笔仓位、给盘加自选当交易指令。

所有命令都要带插件前缀 `a` 或 `股票`，例如 `a模拟盘列表`。下文表格里省略前缀。

---

## 快速开始

```
a模拟盘策略列表                            # 现在能选哪些策略
a模拟盘初始化                              # 建默认盘（100 万，均衡多因子）
a模拟盘创建 放量盘 volume_extremum 500000  # 再建一个底部放量 / 顶部放量盘
a模拟盘列表
a模拟盘查看 放量盘
a模拟盘推送添加 放量盘                      # 本群订阅这个盘的成交
```

针对某个盘的命令必须写盘名，光发「模拟盘查看」只会回用法。名字对不上请先 `a模拟盘列表`。

---

## 策略

目前只预设两套。建盘和换策略**只能从这里选**（`a模拟盘策略列表`），不能自造策略名。

两套策略挂的研究工具不同：

| 策略 id | 名称 | 怎么做决定 | 决策时主要用什么 |
|---------|------|------------|------------------|
| `multi_factor`（默认） | 均衡多因子 | AI 综合技术、基本面、舆情、波动率选股；买入必须带数值止损 | 指标、财报、估值、板块、新闻 |
| `volume_extremum` | 底部放量 / 顶部放量 | **函数先判定结构**，AI 只在结构成立后选标的、写止损 | `papertrade_volume_scan` + 少量日 K 指标；**不扫财报/榜单** |

### 量能策略如何判断顶底

不是让模型看图说「这是底部」，而是两级函数，并尽量少打行情接口：

1. **月 K 粗筛（默认 1 次请求）**：近 **5 年**月线（约 60 根），算收盘价在这 5 年里的分位。买要求 ≤ 0.25，卖要求 ≥ 0.75。不过关**不再拉日 K**。
2. **日 K 确认（再 1 次请求）**：只对过了粗筛的票，拉近 **60 个交易日**。日分位 ≤ 0.15 才算局部底部，≥ 0.85 才算局部顶部；当日量 / 近 20 日均量 ≥ 2.0 算放量。底放量买默认还要求收阳。
3. **缓存**：月 K 6 小时，日 K / 结构结果 30 分钟。同一轮决策+成交不会打两次。

已触发止损的卖单（`stop_triggered`）不受「必须顶部放量」限制。

`a模拟盘策略列表` 会列出每套策略的参数默认值。参数越界会被夹到合法区间。

## 命令

### 建盘 / 管理（群主 / 管理员）

| 命令 | 说明 |
|------|------|
| `模拟盘初始化 [资金]` | 建或自愈**默认盘**（`默认模拟盘`，100 万，`multi_factor`） |
| `模拟盘创建 <盘名> [策略id] [资金]` | 新建命名盘。策略必须是列表里的 id；省略则用 `multi_factor` |
| `模拟盘改名 <旧名> <新名>` | 改名，账本和心跳树跟着 `account_id` 走 |
| `模拟盘删除 <盘名>` | 删盘 + 账本 + 心跳树，不可撤销 |
| `模拟盘停用 <盘名>` / `模拟盘启用 <盘名>` | 停用后不再跑心跳、不烧额度；账本保留 |
| `模拟盘策略切换 <盘名> <策略id>` | 换策略并按新策略重建心跳树；持仓流水保留 |

不带参数发 `模拟盘创建` 会打印可选策略清单。

### 播报（群主 / 管理员）

| 命令 | 说明 |
|------|------|
| `模拟盘推送添加 <盘名>` | 当前群订阅该盘成交 |
| `模拟盘推送删除 <盘名>` | 当前群退订 |
| `模拟盘推送列表` | 本群订了哪些盘（任何人可看） |

建盘时会自动把**建盘所在群**加为订阅方。

### 查询（任何人）

| 命令 | 说明 |
|------|------|
| `模拟盘列表` | 所有盘的策略 / 状态 / 现金 / 总资产 / 收益 |
| `模拟盘策略列表` | 可选策略和默认参数 |
| `模拟盘查看 <盘名>` | 账户 + 持仓 + 近 5 笔（图） |
| `模拟盘持仓 <盘名>` | 持仓卡片（今日涨跌 + 浮盈） |
| `模拟盘收益 <盘名> [周期]` | 已实现盈亏；周期 = 日/周/月/季/年/ytd/总 |
| `模拟盘记录 <盘名>` | 最近 20 笔流水 |

### 运维（管理员 / master）

| 命令 | 说明 | 权限 |
|------|------|------|
| `模拟盘排行` | 跨盘收益率排行图 | 管理员 |
| `模拟盘查询 <盘名或旧群号>` | 文本明细 | 管理员 |
| `模拟盘清盘 <盘名>` | 清 DB / Kanban / 调度残留 | master |
| `模拟盘对账` | 删幽灵仓、更正卖出现金多记的盈亏、回写净值、补播报路由 | master |
| `模拟盘模拟测试` | 全链路 dry-run（独立临时盘） | master |

## 盘名

- 2～16 个字符：中文、字母、数字、下划线；不要空格和 `-`
- 不能是纯数字（会和群号查询混）
- 不能叫周期词（日/周/月/…）或命令词（列表/创建/删除/…）
- 全局唯一；全角会转半角，**大小写敏感**（`VolPool` ≠ `volpool`）

---

## 风控与撮合

风控是盘内规则，用户命令改不了。默认「平衡」模式大约是：单只仓位 25%、单日最多 6 笔、止损 −8%、总回撤熔断 −20%。现金留到 80% 以上是合法状态，不强求满仓。

撮合按 A 股规则：东财最新价成交、100 股整手、佣金 max(成交额×0.025%, 5 元)、卖出印花税 0.05%、T+1、非交易时段拒单。

---

## 成本

每个启用中的盘，每个交易日大约十几次模型调用。启用盘有数量上限（默认 5），超了要先停用别的盘。停用只停心跳，账本还在。

---

## 升级后老数据

第一次启动会自动迁移：最早的老账户变成 `默认模拟盘`，持仓/流水挂到这个盘上，原群写成一条播报订阅。以后同群可以再建第二盘，不会被启动脚本删掉。

## 常见问题

**这是真钱吗？**  
不是。只写插件自己的表。

**一个群能有几个盘？**  
群不拥有盘。一个群可以订很多盘，一个盘也可以推很多群。

**为什么「模拟盘查看」只回用法？**  
必须写盘名，例如 `a模拟盘查看 放量盘`。先 `a模拟盘列表` 看有哪些盘。

**群里没有成交冒泡？**  
看 `a模拟盘推送列表`、盘是不是 🟢 启用、是不是交易时段、WebConsole 里心跳树在不在。

**换策略会清仓吗？**  
不会。只重建心跳、策略参数回到默认。

**怎么重来？**  
`a模拟盘删除 <盘名>`，或 master 用 `a模拟盘清盘 <盘名>`。
