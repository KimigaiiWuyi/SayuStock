# 重大事件怎么用：反转规律与信息层级

> 本篇回答宏观第三问「这件事到顶了吗」，并给出把宏观结论落到仓位的原则。

## 三层信息可得性：宏观 > 行业 > 个股

- 宏观数据（利率、油价、PPI、政策）公开、及时、人人可得。
- 行业数据（产能、出栏、订单）散户和低能力模型几乎拿不到准确值。
- 个股真实经营只有公司里几个人知道，调研也常常祛魅。

结论：**你最可靠的判断在宏观层**。所以决策顺序必须是「先定档位 → 再选行业 →
最后才挑个股」。个股故事再好，档位是防御就不重仓；榜单靠前、财报亮眼都不能越档。

## 突发事件的反转点：不能更坏 / 不能更好

政策、地缘这类**人为可逆**事件引发的暴涨暴跌，拐点出现在「事情不可能再更差 / 更好」
的那一刻。判断办法是问两句：
1. 这件事还能更坏吗？
2. 如果更坏，当事各方承受得了吗？

承受不了 → 已到极限 → **政策顶 = 情绪底**，准备反向。

历史例子（只记逻辑，不记数字）：
- 关税互加到双方根本不可能再做生意的税率，再加已无意义 → 到顶；市场低开高走翻红
  是聪明钱进场信号。全面脱钩不可能发生，所以反向做多胜率高。
- 油价涨到全球经济承受不了的水平 → 到顶。
- 地缘冲突升级到对轰极限、再升级就是没人敢做的地面战 → 到顶。
- 国家队减仓减到无可再减 → 否极泰来。

配套动作：
- 事件第一天不重仓抄底，也不在暴跌当天割肉。
- 等「加码到无意义 / 当事方口风软化 / 低开高走翻红」中至少两个出现再动。
- 反向仓位单票 ≤5%，reason 里写清「为什么认为已到顶」。

## 这条规律对什么不适用

产业内卷（多晶硅、猪价这类供需没变的商品跌价）**不适用**：全行业亏损也能继续跌，
因为产能过剩是长周期客观存在的，不会因为某个人的意志一夜反转。
对行业 / 个股用「跌无可跌」赌反转，胜率会明显低于对政策 / 地缘事件用。

## 两种被长期验证的赢法

- **价值股做左侧**：先确认真有价值（股息率硬指标、垄断护城河、几年内盈利不会大滑），
  下跌到目标区间分批买，拿得住——拿得住的前提是自己真懂逻辑，不是跟单。白酒这类未来盈利没保证的是伪价值股，别当价值左侧买。
- **成长股做右侧**：产业是否爆发、龙头是否浮现都不确定，十倍股背后是一堆退市的。
  确认「大概率跑赢」后再锦上添花，启动期够长，右侧也能吃到大段。

反面：追价值股右侧（涨起来才买高股息）、赌成长股左侧（产业没兑现先重仓），
都是散户长期亏钱的模式。

## 把宏观落到仓位：三档

- 进攻档：钱多 + 无高危 risk_off 事件 + 成长相 / 轮动相 → 总仓 ≤80%，单票 ≤15%。
- 中性档：信号矛盾或看不清 → 总仓 ≤60%，单票 ≤10%，成长价值各半。
- 防御档：钱少（油价 >100 / 美债美元双升）或高危 risk_off 事件进行中 → 总仓 ≤30%，
  单票 ≤5%，只买高股息 / 公用 / 必需消费 / 上游资源。

档位变差时先减估值最高、波动最大的持仓；档位变好时先加有业绩支撑的龙头，
再考虑弹性品种。
