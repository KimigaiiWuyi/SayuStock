# 钱多还是钱少：流动性判断的底层逻辑

> 本篇回答宏观第一问「市场上钱多还是钱少」。结论优先，推导从简。

## 货币的根不是央行，而是「卡脖子」的商品

一国货币能被别人持有，靠的是这个国家握着别人非买不可的东西：石油、稀土、上游原材料、
别人做不出来的制造品。央行只是显示屏，这些「垄断要素」才是主机。

判断规则：
- 垄断要素**供给放宽、价格走低** → 全世界的「钱」变多 → 高估值、高杠杆资产最受益
  （科技成长、小微盘、比特币、白银）。
- 垄断要素**供给收紧、价格飙升** → 全世界的「钱」变少 → 上述资产最先被杀，
  低估值高股息、债券相对抗跌。
- 只有能卡别人脖子的商品涨价才算「收紧」；衬衫涨价不算，稀土 / 石油涨价才算。

## 油价是全球流动性的水龙头

美元的根在石油。石油运不出来、油价飙升，等价于美元收紧、全球实际利率上升。
所以看全球钱多钱少，第一眼看油价方向，第二眼看长端美债收益率和美元指数是否同升。

低能力模型的简化判据：
- 布伦特油价站上 100 美元并且还在涨 → 钱少（防御档信号）。
- 油价长期低迷（几十美元晃）→ 钱多（成长类资产的养肥期）。
- 长端美债收益率 + 美元指数一起冲高 → 全球收紧；一起回落 → 放松。

## PPI 是中国流动性的水龙头

中国制造业占全球三成以上，是有垄断势力的大国。所以中国的 PPI**不是需求的结果，
而是周期的源头**：政府系统性抬高中上游要素价格 → PPI 上行；压低 → PPI 下行。

PPI 上行周期的含义：
- 中上游企业和地方政府的资产负债表在修复 → 价值股 / 上游资源股修复。
- 人民币偏强、国内利率抬升 → 风格从成长向价值倾斜。
- PPI 环比连续转正就是拐点信号，不必等同比转正。

PPI 下行周期：宽松、利率下行、成长风格占优。

「反内卷」提价针对的是中国有国际垄断地位的产品，提价会**增加**垄断利润，是利好；
把它理解成「涨价抑制消费」是把中国当成了没有定价权的小国。

## 汇率三支柱：出口份额、利率、外汇储备

- 出口份额是根。份额大的国家（中国）即使利率远低于美国，汇率也能稳甚至升。
- 出口没落、政府债务太高不敢加息、只剩外储硬撑的国家（日本），汇率易贬难升；
  一天几个点的大波动多是官方干预，不是趋势反转。
- 普通国家要守利率平价（本国利率 ≥ 美国），超级大国可以超越它。
  超级大国重构体系时会出现很多反常识现象，不要用常识去猜。

## 中国的「内需弱」不是通缩

外需强、内需弱的组合是**服务业收缩**，不是货币现象。关税、制裁让外循环受阻时，
政策会转向扩大内需、发展高质量服务业（好房子物业链、服务消费）。
看到外部摩擦升级，除了想到出口链受损，也要想到内需政策会跟上。
