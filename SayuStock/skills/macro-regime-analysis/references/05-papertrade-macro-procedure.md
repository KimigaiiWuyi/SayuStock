# 模拟盘 / 持仓分析的宏观操作手册

> 本篇是给决策代理照着做的流程与写法，不讲道理只讲步骤。

## 每轮固定三问

问 1「钱多还是钱少」：看油价方向、长端美债 + 美元指数、国内 10 年国债、PPI 环比。
只写一个词：钱多 / 钱少 / 不明。

问 2「哪一相」：利率极低 + 楼市冷 = 成长相；利率上行 + 楼市暖 = 价值相；否则轮动相。

问 3「有什么大事」：`macro_event_list(status="open")`。对每件 open 事件回答
「还能更坏吗 / 承受得了吗」，标出是否到顶。表里没有的大事先 `macro_event_upsert` 登记。

三问答完 → 定档（进攻 / 中性 / 防御）→ 写一句依据。

## 定档规则速记

- 进攻：钱多 + 表内无 severity≥4 且 risk_off 的 open 事件 + 成长相或轮动相。
- 中性：三问里任何一问答「不明」，或信号互相矛盾。
- 防御：钱少，或表内有 severity≥4 且 risk_off 的 open 事件。

系统硬闸：表内存在高危 risk_off 事件时，buy 不许标「进攻」，写了会被拒单。

## 档位 → 仓位

| 档位 | 总仓上限 | 单票上限 | 允许买什么 |
|------|----------|----------|------------|
| 进攻 | 80% | 15% | 成长 / 科技 / 出口制造 + 少量价值 |
| 中性 | 60% | 10% | 成长价值各半 |
| 防御 | 30% | 5% | 高股息 / 公用 / 必需消费 / 上游资源 |

事件出现「政策顶 = 情绪底」信号时，任何档位都允许 ≤5% 的试探性反向，但 reason 必须写清依据。

## reason 与 indicators 的写法

decision reason 开头固定 20~40 字：

```
宏观:{档位}|{相}|{一句依据}
```

例：
- `宏观:防御|成长相|油价站上109且红海航道受阻,中美关税战open(sev4)`
- `宏观:进攻|成长相|美债美元双回落,PPI环比连正,表内无risk_off大事`
- `宏观:中性|轮动相|油价回落但美联储决议未落地,等信号`

buy 的 indicators / snapshot JSON 顶层必须带：

```json
{"macro_regime": "防御", "macro_note": "油价站上109且红海航道受阻", "plan_stop_pct": -0.06}
```

缺 `macro_regime` 或 `macro_note`（<8 字）→ 硬闸拒绝，并提示缺什么。

## 常见错误

1. 只写技术指标（MACD 金叉 / KDJ 超卖）就 buy —— 证据不足，硬闸会拒。
2. 把「大盘今天涨了 1%」当宏观结论 —— 那是情绪面，不是钱多钱少。
3. 表里有高危 risk_off 事件还标进攻 —— 被拒后不要换个词硬写，改档位并缩仓位。
4. 对已经 settled 的事件反复 web_search —— 浪费 token，settled 就不查。
5. 每轮都为同一事件重新联网 —— `stale=false` 的事件直接沿用 result。
6. 把宏观档位写进 reason 却不落到仓位 —— 档位是仓位上限，不是装饰。
7. 事件第一天暴跌就重仓抄底 —— 等「加码无意义 / 口风软化 / 低开高走翻红」中两个再动。

## 一个完整示例

```
Phase 3：
  macro_event_list → [us_china_tariff_2026: open, sev4, risk_off, result="双方互加至84%，
  谈判窗口未定"] ；stale=false
  get_market_overview → 上证 -0.8%，跌多涨少；get_latest_news → 油价 +3%，美债 4.6%
  三问：钱少 / 成长相 / 关税战未到顶（还能加、双方仍在加码）
  定档：防御
Phase 5：
  候选 A（高市梦率科技）→ hold，reason 开头「宏观:防御|成长相|油价升+关税战sev4」
  候选 B（高股息公用）→ 试探 buy 5%，indicators 带 macro_regime=防御, macro_note=…,
  plan_stop_pct=-0.05
```
