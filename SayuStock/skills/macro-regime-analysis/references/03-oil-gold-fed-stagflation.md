# 油价、黄金、美联储与滞胀

> 本篇是第一问「钱多钱少」的海外部分：油价冲击、黄金、美联储怎么读。

## 「养殖场模型」：养肥期与收割期

把全球经济想成一个养殖场：养肥期敞开供应饲料（垄断要素供给宽、油价低），大家现金流
充沛、敢做星辰大海的梦、估值越来越高；收割期收紧饲料（油价高），高估值的先被宰。

对应到资产：
- 养肥期占优：成长股、贵金属、科技、中国的小微盘。这些头寸都隐含「油价会长期低」。
- 一旦市场**确认**油价将长期高位 → 成长类被大规模抛售 → 收割期。
- 价值股长期萎靡的根本原因，是周期迟迟没进入收割期。

信号：**金油比**。金油比极高（黄金相对石油贵得离谱）= 火鸡吃得太饱；油价急升、
金油比快速收敛 = 屠刀已经举起。

## 滞胀不是央行造成的

流行说法「高油价 → 通胀 → 央行加息 → 衰退」把央行地位抬太高了。实际是：
石油供应收紧 → 全球实际利率自然上升 → 生产收缩。央行加息**解决不了**航道封锁。

油价 > 100 且还在涨时的操作含义：
- 减成长仓、避开高市梦率、不追刚被油价砸下来的票。
- 转向有现金流的上游资源、高股息、必需消费。
- 小国央行会被迫跟随收紧（怕外储被击穿），别指望它们逆势放水。

## 黄金：和整个法币体系对偶

黄金涨不是「美元完了」，而是**所有法币一起对黄金贬值**——因为大国在扩大垄断要素供给
（放水养鱼），法币背后的垄断利润变薄。

- 大国一起扩供给 + 生产力没跟上（战争、贸易摩擦抑制需求）→ 黄金最好的组合。
- 大国一起收供给 → 黄金也能被打回去。周期漫长，不建议重仓押黄金。
- 黄金的「避险」属性在某些冲突中会失灵（它已经被资金炒过一轮时尤其如此）。

## 美联储：别只看「加息 / 降息」四个字

美国当前是「数量 + 价格」双约束体系，直觉会反：
- 加息 + 扩表 = 偏宽松组合；降息 + 缩表 = 最严紧缩。
- 隔夜逆回购（RRP）余额综合了两种约束：余额枯竭 = 约束变紧 = 美元流动性拐点。
- 比特币、纳指先于其他资产反映美元外围 / 核心流动性转弱。

低能力模型简化：看**长端美债收益率 + 美元指数**同升 = 收紧，同降 = 放松；
议息决议本身更像仪式，市场怎么走看金融条件松紧。

## 美国的两条路径与收益率曲线

- 传统势力路径：打仗 → 换能源中枢 → 制造业回流。副作用是推高国际油价与实际利率。
- 科技势力路径：AI 资本开支拉动全要素生产率。副作用是巨量融资、货币增长。
- 两条路都会推高整条收益率曲线；30 年美债创多年新高 = 政策工具已兜不住。
  这种时候海外风险资产波动会放大，A 股的外资偏好也会受影响，档位往中性 / 防御靠。

## AI 泡沫情景下什么抗跌

若 AI 资本开支骤减引发全球风险资产回撤：高股息 / 消费类与科技呈负相关，是「低风险做空
AI」的方式；工业金属（铜）随需求走弱；长端债券是危机时反应最快的避险资产。
这不是预测，是**情景预案**：出现 AI 龙头财报亮眼却大跌、韩股领跌等信号时启用。
